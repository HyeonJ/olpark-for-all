# 3안 검토 — 모두의 올팍

1안의 정보 순서와 수치는 유지하고, 읽는 자료에서 방문 준비에 쓰는 모바일 서비스로 표현을 바꿨다. 녹색은 브랜드와 주요 행동에 집중하고, 본문은 흰색·중성색으로 정리했다. 요약 화면과 지도 화면은 세로로 이어진다.

## AI 티 신호 → 어떻게 바꿨나

| AI 티 신호 | 3안에서 바꾼 방식 |
| --- | --- |
| `BEFORE YOU GO`, `FACILITIES`, `MAP VIEW` 같은 영어 아이브로 | ‘방문 전에 확인해 주세요’, ‘편의시설 지도’ 등 이용 목적을 바로 알 수 있는 한국어로 변경. 화면 사이 설명도 한국어로 작성했다. |
| 01·02 번호와 전시 패널 같은 섹션 시작 | 번호를 없애고 제목, 배경 띠, 콘텐츠 묶음으로 구분했다. |
| ‘도착하면, 여기부터.’ 같은 광고형 제목 | 지도는 ‘편의시설 지도’, 숫자 영역은 ‘10시 주차대수’로 직접 명명했다. |
| 제목마다 붙는 마침표와 시적인 말투 | 제목은 짧은 문장 또는 명사형으로 끝내고, 설명은 해요체로 작성했다. ‘오전 10시는 오후보다 덜 붐볐어요’ 옆에 ‘작년 기록’을 붙여 비교 시점도 드러냈다. |
| 항목마다 반복되는 ‘공식 정보 / 전화 확인 / 위치 참고’ 꼬리표 | 반복 라벨을 제거했다. 대여는 ‘전화로 확인해 주세요’, 화장실은 ‘현장 위치와 이용 가능 여부를 확인해 주세요’처럼 필요한 설명에 포함했다. |
| 과거 기록의 단서가 본문 끝에 몰려 있음 | 결론 위에 ‘작년 기록’, 숫자 옆에 ‘작년 중앙값’을 배치했다. 차트 바로 아래에도 ‘방문일의 예측은 아니에요’를 남겼다. |
| 같은 간격, 같은 얇은 선으로 이어지는 편집물 느낌 | 큰 영역은 8px 배경 띠로 나누고, 체크 항목에는 구분선 대신 아이콘과 간격을 사용했다. 전화 안내, 차트 비교, 지도, 장소 상세는 각각 필요한 형태로 표현했다. |
| 화면 전체를 덮는 녹색과 작은 회색 설명 | 본문은 짙은 중성색, 녹색은 핵심 비교와 전화 버튼에 사용했다. 제목 20~28px, 주요 숫자 40px, 본문 14~16px로 위계를 분명히 했다. 출처는 12px로 한정했다. |
| 웹 페이지 같은 로고와 우측 작은 세그먼트 | 상태바 시안 아래 58px 상단 바와 밑줄형 ‘방문 요약 / 편의시설 지도’ 탭을 배치했다. 방문 조건은 바로 아래 회색 요약 행에서 펼쳐 본다. |
| 문장은 행동을 권하지만 실제로는 설명으로만 이동 | 첫 전화 안내가 실제 `tel:024101114`로 연결된다. 하단 고정 ‘대여 문의 전화하기’에서도 바로 전화할 수 있다. |
| 스크롤 중 주요 행동이 사라짐 | 하단 고정 바에 전화와 화면 이동을 배치했다. 지도 영역으로 내려가면 보조 이동이 ‘방문 요약’으로 바뀐다. |
| ‘자세히 보기’처럼 결과를 알기 어려운 버튼 | ‘공원 안내 전화하기’, ‘지도에서 위치 보기’, ‘네이버 지도’, ‘방문 요약으로’ 등 결과가 보이는 이름을 사용했다. |
| 실시간 숫자에 업데이트 정보가 없음 | ‘예시 데이터’ 칩과 ‘업데이트 시각 없음 · 실시간 연결 전 고정 예시’를 숫자 바로 아래에 표기했다. 실제 조회한 것처럼 시각을 꾸미지 않았다. 시설 정보에는 실제 대조일 2026.11.25를 표시했다. |
| 수량 불일치를 경고문으로 길게 노출 | ‘주차·유모차 수량은 확인이 필요해요’라는 접힌 안내로 정리했다. 열면 출처별 표현, 날짜, 전화 문의가 나온다. 확인 필요 자체는 접혀 있어도 보인다. |
| 클릭할 수 있을 것 같지만 동작하지 않는 지도 필터 | 세 필터가 실제로 시설 표시를 켜고 끈다. 선택 상태는 체크와 `aria-pressed`를 함께 제공한다. |
| 고정된 장소 카드와 의미 없는 순번 | 대여소 마커와 ‘다른 편의시설’에서 장소를 선택하면 제목·유모차 안내·네이버 지도 대상이 바뀐다. 선택 카드의 순번은 없앴다. |
| 모든 장소가 같은 정보를 가진 것처럼 보임 | 동1문을 선택하면 확인되지 않은 수유실 칩을 표시하지 않는다. 수유실은 별도 목록에서 ‘안내센터 · 한성백제박물관 1층’으로 안내한다. |
| 지도 약어가 낯설고 영문 중심 | `WC`, `P`, `N` 대신 휠체어 기호, ‘주차’, ‘북’을 사용했다. 지도 범례는 한국어로 제공한다. OpenStreetMap 저작자 표시는 유지했다. |
| 펼침과 버튼 모양만 만들고 접근성은 빠짐 | 실제 `details/summary`, 링크, 버튼을 사용했다. 키보드 포커스를 표시하고 대여소 선택 후 장소 제목으로 포커스를 이동한다. 주요 터치 영역은 44px 이상이며 지도 마커의 투명 터치 영역도 확대했다. |

## 유지한 데이터와 해석

- 방문 조건: 2026.11.28 토요일, 10시 도착, 휠체어 동행. 펼치면 시안의 고정 조건임을 안내한다.
- 10시 중앙값 1,423대, 보통 범위 1,180~2,198대, 2025년 가을 주말·휴일 15일. 15시 2,334대 대비 911대 적고 약 61%다.
- 6~21시 중앙값: `[481, 648, 957, 1259, 1423, 1534, 1713, 2014, 2285, 2334, 2095, 1699, 1407, 1305, 801, 496]`. 원본 차트를 재사용하고, 펼침 안에 숫자 표도 제공한다.
- 여유 1,243대 이하, 보통 1,244~2,035대, 붐빔 2,036대 이상. 범위의 사분위수와 상태 분류 기준은 다르므로 펼침에서 각각 설명한다.
- 실시간 예시 1,974대는 동2·남2·북2 합계이며, 남은 주차 공간이나 예측값으로 표현하지 않는다.
- 장애인 주차는 API ‘140칸’과 웹 ‘주차 개수 140’을 그대로 병기한다. 웹의 140을 장애인 전용 주차면 수로 확정하지 않는다.
- 휠체어 대여는 평화의광장 앞 공원안내센터·동1문 안내센터. 공개되지 않은 수량과 당일 가능 여부는 전화 확인으로 안내한다.
- 유모차는 API 평화의광장 앞 4대·동1문 3대와 웹 ‘4대’를 병기한다. 합계나 현재 재고를 만들지 않는다.
- 수유실은 안내센터·한성백제박물관 1층. 공원 안내는 02-410-1114다.
- 한국체육산업개발, 한국관광공사 무장애 여행 정보 API·공식 웹, OpenStreetMap의 출처를 관련 영역과 펼침 상세에 남겼다. 원본의 이상·집계 변경 의심 102일 제외 설명도 유지했다.
- 지도는 시설 위치 참고용이다. 화장실 현장 확인 필요와 공원 내 경로 안내 미제공을 지도 바로 아래에 표시한다. 네이버 지도 연결을 휠체어 접근 가능 경로로 보증하지 않는다.

## 구현 및 검수 범위

- 단독 정적 HTML인 `design-3.html`에 스타일, SVG, 동작 코드를 포함했다. Pretendard는 1안과 같은 CDN을 사용하므로 폰트 로딩에는 네트워크가 필요하다.
- 최대 너비 412px이며 더 작은 화면에도 줄어든다. 하단 고정 바 아래에는 안전 영역을 반영했다. 상태바 9:41은 기기 화면 표현용이며 데이터 업데이트 시각이 아니다.
- 로고 SVG 내용과 공원 경계·물의 모든 SVG path는 1안 그대로 유지했다.
- 본문·버튼·칩·차트·지도에서 사용하는 텍스트 색상 20개 조합을 계산했다. 최소 대비는 5.14:1로, 4.5:1 기준을 충족했다. 상태와 선택은 글자·체크·밑줄로도 구분한다. 키보드 포커스와 동작 줄이기 설정을 지원한다.
- 원본 SVG·수치 보존, HTML 참조·구조, JavaScript 문법과 주요 선택/필터 동작은 정적 분석 및 DOM 모의 실행으로 확인했다.
- 이 실행 환경에서는 브라우저의 소켓 생성이 차단되어 `agent-browser`와 Chromium 실행에 실패했다. 따라서 실제 렌더링, 폰트 로드, 줄바꿈, 스크린리더, 외부 네이버 지도 연결은 브라우저에서 추가 확인이 필요하다.
